## A. 多元规律

世间万物受多领域规律共同作用。人的直觉是单一、片面的。

借用各学科成熟规律交叉判断，才能规避认知误区。三层结构：

- **底层**：物理、心理、经济、生物等基础学科的核心原理
- **中层**：独立思维工具（复利、逆向、能力圈、机会成本…）
- **顶层**：多模型同步分析同一件事，结论互相对照，整合推演

三个学习顺序（也是能力顺序）：
1. 建立独立思考能力
2. 练习多角度看待同一件事
3. 积累多学科基础规律，充实模型工具库

> "多模型"不是名词的堆砌。用了 3 个模型但结论一致，等于用 1 个。

## B. 阴阳转化

核心一句话：**阴和阳两股力量交缠、转化、合为一个整体，螺旋往上。**

- 不是选阴或选阳，不是谁替代谁
- 阴中有阳，阳中有阴
- 阴到极点生阳，阳到极点生阴
- 转化永不停歇

### 三层结构

1. **阴在底层托着** —— 积累、骨架、慢的
2. **阳在外层推着** —— 输出、表层、快的
3. **交汇处是质变节点**

### 运行规律

- 阴到极点 → 生阳（积累够了 → 输出）
- 阳到极点 → 生阴（输出收反馈 → 新积累）
- 循环往复，螺旋往上

### ⚠ 可证伪要求

**"极点"必须在事前被定义，否则这句话什么都解释不了。**

- ❌ "我觉得差不多了，该爆发了"
- ✅ "当 X 指标连续 3 次下降且 Y 出现，就是极点；到那时我做 Z"

事前写不出这个，就不要用"阴到极点"当理由。

## C. 系统结构

看问题先看结构：由什么构成？各部分什么关系？核心根在哪？

现象是果，结构是因。改结构才有用，改现象只是安慰。

## D. 杠杆

| 要素 | 是什么 | 性质 |
|---|---|---|
| 支点 | 底层心法、核心能力、长期原则 | **定量，不动** |
| 杠杆 | 技术、经验、思维 | 变量，围绕支点积累，越长撬力越大 |
| 缝隙 | 还没有的东西 | 从无到有的发力入口 |

### 缝隙四类

| 维度 | 缝隙是什么 |
|---|---|
| 个人能力 | 缺点、短板、知识盲区 |
| 市场/机会 | 未发掘、未满足的需求与赛道 |
| 人际关系 | 误会、隔阂、关系空白、潜在联结 |
| 成长进程 | 现状与目标之间的未知区间 |

### 四步找缝隙

1. **锚定支点** —— 明确不变的核心
2. **对比落差** —— 现状 VS 目标，差值即缝隙
3. **查看衔接** —— 两个模块衔接不畅、断层处
4. **自问核验** —— 这个领域目前还没有什么？

### 完整使用流程

1. 守住支点
2. 将杠杆架入缝隙
3. 持续施压：稳步投入、反复行动
4. 结果验证：产生变化 → 方向对，继续；毫无动静 → 定位偏差，调整

### 区分

- **缝隙 ≠ 问题**：缝隙是原本空白，问题是已有破损
- **缝隙 ≠ 风险点**：风控找隐患（规避），杠杆找缝隙（利用）

### ⚠ 可证伪要求

1. **支点必须可测。** "核心能力"是不可测的。写成"我在 ___ 上的下限是 ___，不随项目变"。
2. **压必须有三件套。** 期限 + 判定信号 + 到点无条件复盘。
   没有时间窗的"持续施压"就是死扛——而 F 的第 3 条恰恰在骂"短视换方向"和"死扛"两种病。**判据不写清，这套系统可以同时论证"该坚持"和"该放弃"。**

心法：
- 支点越稳，杠杆越长
- 缝隙是结构与结构之间的接口
- **压了才知道，不压永远不知道。想通了要压，光想不压等于没想。**

## E. 追根（root_system）

**追根溯源，持续施压，系统自现。**

四步闭环：

| 步 | 动作 | 判据 |
|---|---|---|
| **追** | 追问本质，不追到根不罢休 | 能被"再问一个为什么"而不倒 |
| **找关键** | 精准定位重要信息和关键词（瞄准器） | 一句话能说出关键变量 |
| **压范围** | 压整个"还没有"的区域，不压单个点 | 范围在缩小，结构在显形 |
| **验系统** | 验证系统有没有**转**，不是验证结论对不对 | 有领先信号动了 |

### 三层展开

- **追到根**：追问本质
- **追到面**：范围思维，压整个区域
- **追到转**：验证系统有没有动

### 压的精准定义

**压 = 缩小"没有"的范围。**

不是填补一个缝隙，是把整个"还不知道"的区域往下压，让里面的结构一个一个显出来。

面团放那儿不动，里面什么形状你不知道。压一下，紧一分，结构出来一点。再压，再紧，再出来一点。直到整个区域压实，结构全显形——那就是你的系统。

- 压不是用力，是**缩小范围**
- 压不是填坑，是**让结构自己露出来**
- 压不是一次，是**持续，直到显形**

心法：**不是够用，是想通。**

## F. 反向：废掉路径

废掉不是一夜之间，是一条链：

```
贪图轻松，放弃精读和刻意练习
  → 闲置九步法，做事全凭感觉
    → 短视追逐即时利益，频繁换方向
      → 长期身处糟糕环境 + 消极圈层，不断内耗
        → 害怕试错不敢创新，开始跟风模仿
          → 空有眼界没有成果，韧性被磨光
            → 彻底沦为平庸
```

链条是**单向不可逆**的：越往后越难回头。所以要找的永远是最**靠前**的失效点，不是最显眼的那个。

任何分析交付前都要问一句：**我是不是正在走这条路？**

## 公理之间的关系

```
        A 多元（看几个方向）
              ↓
        C 结构（看到底是什么）
              ↓
     B 阴阳 ── E 追压 ── D 杠杆
     （怎么转化）（根在哪）（从哪使劲）
              ↓
           F 反向（别走废路）
```

A/C 是**看**，B/E/D 是**动**，F 是**刹车**。缺一个都会出事：

- 缺 A → 片面
- 缺 C → 治现象
- 缺 E → 治不了根
- 缺 D → 找不到发力点
- 缺 F → 一路滑下去还不自知

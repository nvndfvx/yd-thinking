# flow: structure（两头中间）

> 原「两头中间法」。**结果倒推路径：先定人物弧线的起点和终点，再往里填事件。**

## 命中
内容是剧本 / 故事 / 分集 / 结构问题。`mode = lean`。

## 七步

| # | 步 | 动作 | 产出 |
|---|---|---|---|
| 1 | 定弧线 | 开头什么状态？结尾变什么状态？ | `arc.start` / `arc.end` |
| 2 | 找转折点 | 从结尾倒推：中间**必须**经过哪个核心转折？ | `arc.turn` |
| 3 | 铺阻碍 | 从开头到转折点，需要几个障碍？ | `arc.obstacles` |
| 4 | 用行动串 | 每个事件之间，人物做了什么从 A 到 B？ | `arc.actions` |
| 5 | 检查因果链 | A→B 有因果吗？没有就换，不能硬连 | `arc.causal_ok` |
| 6 | 删多余 | 跟弧线无关的全删，能合并的合并 | — |
| 7 | 写 | 开头 → 障碍1 → … → 转折 → 结局 | — |

## 第 1 步：三问

- **开头**：缺什么？怕什么？想要什么？（`lacks / fears / wants`）
- **结尾**：得到什么？放下什么？变成谁？（`gains / lets_go / becomes`）

三问里"怕什么"和"放下什么"最常被跳过，而它们决定弧线是否成立。

## 第 2 步：转折点是心脏

从**结尾**倒推，不是从开头顺推。顺推会得到"一堆事情发生了"，倒推才得到"必须发生的那一件"。

判据：删掉这个转折，结局还成立吗？**成立 → 它就不是转折点，是过场。**

## 第 5 步：因果链自检

对每一对相邻事件问：**"如果 A 没发生，B 还会发生吗？"**

- 会 → 是并列，不是因果，合并或删
- 不会 → 因果成立

`causal_ok: false` 时必须写明**哪一处是硬连的**，不许笼统说"节奏有问题"。

## 出口
`arc`（六要素 + turn + obstacles≥2 + actions + causal_ok）/ `decision`

## 反模式
| 病 | 症状 |
|---|---|
| 从开头顺推 | 事件多但没方向 |
| 转折点选在中间偏后但没有前置铺垫 | 观众觉得突兀 |
| 障碍是"坏人使坏"，与人物内在无关 | 弧线没变，只是走过场 |
| 删不掉任何东西 | 说明第 1 步的弧线没定死 |

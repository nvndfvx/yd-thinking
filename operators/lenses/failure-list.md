# lens: failure-list（逆向清单）

> 只做一件事：**定位你正在这条链的第几步。** 不做安慰，不做鼓励。

## 废掉路径链（单向不可逆）

```
1  贪图轻松，放弃精读和刻意练习
   ↓
2  闲置九步法，做事全凭感觉
   ↓
3  短视追逐即时利益，频繁换方向
   ↓
4  长期身处糟糕环境 + 消极圈层，不断内耗
   ↓
5  害怕试错不敢创新，开始跟风模仿
   ↓
6  空有眼界没有成果，韧性被磨光
   ↓
7  彻底沦为平庸
```

## 用法

1. **逐条对照**：我现在在第几步？（可能有多个，取最靠前的那个）
2. **找最早失效点**：最靠前的那一步才是病根，后面的都是症状
3. **追根**：用 `verbs/trace.md` 追到"一个没做过的决定"
4. **换判据**：当初用什么信号能提前发现？→ `signals.system_turning`
5. **落规则**：写成一条第三方能检查的规则 → `failure_chain.warning_triggers`

## 输出字段

```yaml
failure_chain:
  stage: 4                    # 最靠前的失效步
  earliest_failure: str       # 那一步具体发生了什么
  root: str                   # 追到的决定
  warning_triggers: [str]     # 下次的预警信号，≥1，可观测
```

## 每步的"提前信号"（判断自己在不在这一步）

| 步 | 在里面的信号 |
|---|---|
| 1 | 我在找"更省力"的方法，而不是更难的练习 |
| 2 | 我最近的判断没写过理由 |
| 3 | 三个月内换了两次主攻方向 |
| 4 | 我身边的人都在抱怨，且我也在抱怨 |
| 5 | 我在模仿某个成功者，但说不出他为什么成 |
| 6 | 我知道很多，但拿不出一个成品 |
| 7 | 我已经不生气了 |

## 铁律

- **只找最靠前的那一步。** 修第 5 步不解决第 1 步。
- **不评价人，只定位步骤。** "你废了"不是分析。
- **第 7 步不是分析对象**：到第 7 步需要的不是复盘，是换环境。

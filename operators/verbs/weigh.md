# verb: weigh

**一句话**：把维度排出不可平均的次序。**全是 4 分 = 没排。**

## 输入
- `weights[].dimension`（来自 `decompose`）

## 动作

1. **每个维度打 1-5 分。** 依据必须是**事实**，不是形容词。
   - ❌ "这个比较重要" → 权重 4
   - ✅ "这个决定我未来 18 个月还能不能留在行业里" → 权重 5
2. **强制拉开差距**：`max >= 2 * min`。
   拉不开 → 说明维度拆错了，退回 `decompose`，不要在这里硬调分。
3. **强制"只留一个"**：如果只能保一个维度，保哪个？恰好一条 `only_one: true`。
   给不出，就是还没想清楚什么是核心。
4. **写最重的那条的代价**：为了它，我要主动放弃哪个维度？写不出放弃项，说明这分是虚的。

## 输出字段
```yaml
weights: [{dimension, weight, evidence, only_one}]
```

## 判据
- `max >= 2 * min` 成立
- 恰好 1 条 `only_one: true`
- 最重那条能说出"因此我不做 ___"

## 反模式
| 病 | 后果 |
|---|---|
| 全 4 分 / 全 5 分 | 不敢取舍，等于放弃判断 |
| 用形容词当 evidence | 事后无法复盘为什么给这个分 |
| `only_one` 有 0 条 | 没有核心，行动会平均用力 |
| `only_one` 有 ≥2 条 | 其实没排，只是标了两下 |
| 权重和为 100 的百分制 | 精确的假象比粗略的排序更危险，本技能不做百分制 |

# verb: collide（碰撞溯源）

**一句话**：脑子里的东西说出来，让外部的力撞一下，盲点才会现形。

> 没有外部碰撞的"深思"，八成是在自我确认。

## 输入
- 模糊的判断、说不清的感觉、"我觉得是这样但说不出来"

## 八步

| # | 步 | 问自己 |
|---|---|---|
| 1 | **外化** | 我到底想说什么？（说出来，写下来，不许在脑子里过） |
| 2 | **碰撞** | 对方戳中了我的哪个盲点？（不是"他说的对不对"，是"他碰到了哪里"） |
| 3 | **确认** | 我真的理解他在说什么了吗？（复述一遍，看他认不认） |
| 4 | **追问** | 再问一个为什么？（不满足"够用"，追到"想通"） |
| 5 | **验证** | 这个结论我自己信不信？（不是问对不对，是自己确认成不成立） |
| 6 | **整合** | 这个能怎么落地？（结构化，变成可执行的东西） |
| 7 | **记录** | 核心结论是什么？（聊完记下来，不让聊完就散） |
| 8 | **行动** | 下一步做什么？（闭环，不停留在脑子里） |

## 没有外部对象时怎么撞

用**对抗性自我提问**代替（质量低但比没有强）：

- 假设一个比我更懂这行的人，他会先攻击哪一点？
- 假设我 6 个月后失败了，回头看是哪句话当时就该听出来？
- 把结论反过来写一遍，看反过来的版本是不是也能自圆其说（能 → 你还没想通）

## 输出字段
```yaml
strongest_counterargument        # 第 2/4 步的产物
weights[].evidence               # 第 5 步确认过的事实
unknowns[]                       # 第 6 步发现还没查的
```

## 判据
- `strongest_counterargument` ≥25 字，且**不是**"也可能有风险"这种空转
- 至少一条 `unknowns` 是这次碰撞才发现的

## 反模式
- 找了一个只会说"挺好的"的人撞 → 等于没撞
- 把"对方不同意我"当成"对方不懂" → 第 2 步直接跳过
- 聊完不记录 → 第 7 步失败，下次从零开始
